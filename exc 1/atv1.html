INF 321 - PROJETO E DESENVOLVIMENTO DE SISTEMAS PARA A WEB

Bem-vindo à página da disciplina INF 321 - Projeto e Desenvolvimento de Sistemas para a Web!

Nesta disciplina, aprenderemos os principais conceitos, técnicas e ferramentas necessárias para o desenvolvimento de sistemas e páginas web. Ao longo do curso, exploraremos tecnologias como HTML, CSS e JavaScript, desenvolvendo conhecimentos fundamentais para criar aplicações web funcionais, organizadas e interativas

Professor:

LUCAS FRANCISCO DA MATTA VEGI

Descrição:

Introduzir ao aluno conceitos arquiteturais básicos da Web, focando em aspectos de projeto e implementação de sistemas e softwares para a mesma; Treinar o desenvolvimento de aplicações cliente-servidor e de sistemas com comunicação por troca de mensagens; Treinar o desenvolvimento de aplicações multiplataforma; Introduzir o aluno à linguagens de marcação e de folhas de estilo; Prover contato inicial do estudante com tecnologias de desenvolvimento backend; Introduzir, por meio de aplicações Web, conceitos de comunicação assíncrona cliente-servidor e acesso a bancos de dados no servidor.
